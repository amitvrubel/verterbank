# Verterbank

A collaborative Yiddish multilingual dictionary.

## Repository structure

- `apps/` — Applications (backend, frontend, etc.)
- `packages/` — Shared libraries and configuration

## Tech stack

- Node.js
- pnpm
- Monorepo (pnpm workspaces)
- Backend: NestJS
- Frontend: TBD

## Getting started

```bash
pnpm install
```
